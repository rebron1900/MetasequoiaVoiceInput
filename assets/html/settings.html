水杉记言

语音输入设置

配置文件保存在程序目录的 config.toml

语音识别

配置将录音转换为文字的云端服务。

ASR 服务

可选择 HTTP 文件转写，或统一 JSON WebSocket 流式协议。切换传输方式会更新当前 ASR 地址和 Token。

传输方式

流式模式会在录音结束后将 16 kHz PCM16 音频分帧发送到 WebSocket 服务。

API 地址

HTTP 模式填写音频转写接口 URL；流式模式填写 ws:// 或 wss:// 服务地址。

音频分片

每个 WebSocket binary frame 的音频时长，建议 40 ms。

协议录音结束后发送 start JSON、PCM16 binary 分帧和 stop JSON；服务端返回 partial、final 或 error JSON 事件。
API Token

Token 仅保存在本机的 config.toml。

文本处理

在上屏前清理明显的停顿词和重复内容。

文本润色服务

关闭“上屏前文本处理”后，下列接口不会被调用。

服务提供方

用于记录配置来源。

API 地址

Chat Completions 接口的完整 URL。

API Token

可以与语音识别服务使用不同 Token。

常规

调整语音输入的基础行为。

输入体验

偏好语言

用于文本处理的语言偏好。

上屏方式

SendInput 不修改剪贴板；Ctrl+V 会覆盖当前剪贴板内容，以获得更广的应用兼容性。

上屏前文本处理

启用后会在发送文字前调用文本处理服务。

提示音

录音开始和停止时播放提示音。

提示设置保存后需重启水杉记言，新的服务配置和行为选项才会应用到当前运行实例。

关于

水杉记言是可独立使用的 Windows 语音输入工具。

使用方式
按住右 Alt 录音，松开后识别并输入文字。右 Alt + Space 可锁定录音，Ctrl + F9 可切换连续录音。
配置位置
与 MetasequoiaVoiceInput.exe 位于同一目录的 config.toml。
