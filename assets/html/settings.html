传输方式

流式模式会在录音结束后将 16 kHz PCM16 音频分帧发送到 WebSocket 服务。

API 地址

HTTP 模式填写音频转写接口 URL；流式模式填写 ws:// 或 wss:// 服务地址。

模型路径 / 名称

本地 Whisper 填相对程序目录的 ggml 模型路径；云端填模型名称。

音频分片

每个 WebSocket binary frame 的音频时长，建议 40 ms。

协议录音结束后发送 start JSON、PCM16 binary 分帧和 stop JSON；服务端返回 partial、final 或 error JSON 事件。
API Token

关于

水杉记言是可独立使用的 Windows 语音输入工具。

使用方式
按住右 Alt 录音，松开后识别并输入文字。右 Alt + Space 可锁定录音，Ctrl + F9 可切换连续录音。
配置位置
与 MetasequoiaVoiceInput.exe 位于同一目录的 config.toml。
